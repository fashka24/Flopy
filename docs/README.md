# Documentation

## Built-in functions

### puts(...)
```python
# Print arguments(string) to stdout

puts("some", " ", "text\n")
```

### echo(...)
```python
# Print arguments(string) to stdout with new line on end

echo("some", " ", "text")  # Automatic add "\n" on every argument
```

### str(_value)
```python
# Cast non-string type to string

puts(str(123))
```

## Variable declaration

```python
let x = 123

puts(str(x))
```
